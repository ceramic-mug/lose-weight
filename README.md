# Lose Weight

A simple weight-loss helper for iPhone, iPad and Mac, for people who don't want to count every calorie.

- **Log food in three taps.** Pick where it came from (home cooked, fast food, restaurant, cafeteria, packaged, snack or drink), how healthy it was (lighter, balanced or indulgent), and how much (small, regular or large). Tapping the portion saves the meal, and recent meals can be logged again in one tap.
- **Log exercise in two taps.** Pick the type, then tap the minutes. Effort defaults to Moderate, or whatever you used last time.
- **Manual entry comes first.** Apple Health and Apple Watch import is optional and off by default.
- **Short screens.** All explanations live on one Explanations page, reached from the **?** buttons and from Settings.
- **Log weight daily.** Readings are smoothed into a trend line so daily water-weight swings don't discourage you.
- **See your progress.** A daily budget ring, weight and eating charts, an activity calendar, and a weekly report card with plain-language tips.
- **Follows medical guidelines.** Targets and tips come from NIH, CDC, USDA MyPlate, the HHS Physical Activity Guidelines and the Compendium of Physical Activities. See [docs/GUIDELINES.md](docs/GUIDELINES.md).
- **Private.** Data syncs through your own iCloud account. There are no accounts, servers or ads.

## Project layout

```
App/                      SwiftUI app (shared by iOS and macOS)
  Features/               Today, Log (food/exercise/weight), Trends, Insights, Onboarding, Settings
  Persistence/            SwiftData models (CloudKit-synced) and derived summaries
  Health/                 Apple Health import/export (iOS)
  Services/               Navigation, reminders, CSV export
  Design/                 Colors, cards, rings, tiles
  Preview/                Sample data for Xcode previews
Packages/LoseWeightCore/  All guideline math, with no UI code, and unit-tested
Config/                   Entitlements (Info.plist is generated by XcodeGen)
project.yml               XcodeGen project spec
```

## Build and run (on a Mac)

Requirements: Xcode 16 or newer, iOS 18 / macOS 15.

```sh
brew install xcodegen
xcodegen                 # creates LoseWeight.xcodeproj
open LoseWeight.xcodeproj
```

1. In **Signing & Capabilities**, choose your team.
2. The bundle ID is `com.ceramicmug.loseweight`. To use your own, change it in `project.yml` and the files in `Config/`.

To test on an iPhone without a Mac, see [docs/TESTFLIGHT.md](docs/TESTFLIGHT.md).
3. Run on an iPhone simulator or on **My Mac**.

Apple Health only works on a real iPhone or iPad. In the simulator and on the Mac, the app runs without it, and the Mac gets Health-imported data through iCloud.

Every screen has an Xcode Preview that uses 10 weeks of sample data.

## Tests

The core logic (calorie targets, food estimates, exercise calories, weight trend, goal projection, report card and tips) is a plain Swift package. Its tests run anywhere Swift runs:

```sh
cd Packages/LoseWeightCore
swift test
```

Or run them in Xcode with **Product › Test**.
